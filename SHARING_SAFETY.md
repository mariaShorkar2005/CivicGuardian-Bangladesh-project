# Sharing safety

This source archive has been sanitized for sharing. It does not include a live
`.env` file, API keys, database credentials, OAuth secrets, personal
administrator addresses, Git history, dependency folders, or build output.

Before running the project:

1. Copy `.env.example` to `.env`.
2. Replace every placeholder with credentials for your own deployment.
3. Keep `.env` private and never commit it to source control.
4. Install dependencies with `npm ci`.

The example administrator account is `admin@example.com`. Replace it only in
your private environment configuration.

No software license is included in this archive.
